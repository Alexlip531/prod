# Макет главной страницы «Выгул рядом»

Прототип главной страницы сервиса поиска площадок для выгула собак (пилот — Королёв). Концепция и обоснование — в `dog-parks-site-analysis.md`.

## Где файл макета
Полная самодостаточная версия макета (единый `index.html` со встроенными base64-изображениями, ~1 МБ) передана в чат Notion AI 29.07.2026 — открывается в браузере без сервера и интернета. Для публикации в репозитории: загрузить `index.html` и папку `assets/` с пятью изображениями, заменив data URI на пути `assets/*.jpeg`.

## Структура страницы
1. **Шапка** — логотип, навигация (Карта, Площадки, Частные площадки, Гайды, Для бизнеса), CTA «Добавить площадку».
2. **Герой** — H1 «Найди безопасное место для выгула собаки за 3 минуты», строка поиска по городу/району, чипы фильтров с количеством (Огорожено · 14, Освещение · 9, Агилити · 5…), фото с плавающей карточкой «24 площадки в Королёве · 4,8».
3. **Полоса доверия** — 24 площадки, 1 300+ отзывов, 8 районов, 100% ручная проверка.
4. **Каталог** — фильтры по типам (городские / лесные / тренировочные / частные), карточки площадок: фото, бейдж «Проверено», тип, район и расстояние, удобства, рейтинг и число отзывов, ссылка «Подробнее».
5. **Как это работает** — 3 шага: найти на карте → проверить отзывы → прийти и выгуливать.
6. **Частные площадки** (модель Sniffspot) — бронирование приватных слотов, онлайн-оплата, до 80% хозяевам участков; CTA «Узнать о запуске» и «Сдать свою площадку».
7. **Гайды** — контент-хаб под SEO и AI-поиск: обзор районов, правила и штрафы 2026, советы кинолога.
8. **Бизнес-баннер** — лиды для кинологов, грумеров и ветклиник: оплата за заявку или подписка.
9. **Футер** — разделы Сервис / Бизнесу / Контакты (Telegram, VK, почта).

## Дизайн-токены
- Текст `#2C2C2B`, вторичный `#7D7A75`, фон `#FFFFFF`, мягкая поверхность `#F9F8F7`, граница `#E6E5E3`.
- Акценты: синий `#2783DE` (CTA, ссылки), зелёный `#46A171` (бейдж «Проверено»), оранжевый `#D5803B` (рейтинг, «Скоро»).
- Радиусы 8–12 px, границы вместо теней, системный sans-стек, body 16px/1.5, заголовок героя 44px.
- Адаптив: брейкпоинт 820px — одна колонка, форма поиска складывается в столбик, статистика 2×2.
