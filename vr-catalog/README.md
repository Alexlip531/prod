# VR Каталог площадок

Ядро сервиса «Выгул рядом»: тип записи «Площадка» с полным управлением из админки и выводом на главной странице.

**Требования:** WordPress 6.0+, PHP 8.0+ (разработано под PHP 8.3). Рекомендуется тема «Выгул рядом» (использует её стили и фото из `assets/img`).

## Что умеет

- **Тип записи «Площадка»** (`vr_park`) с таксономиями «Тип площадки» и «Район».
- **Мета-поля площадки:** расстояние/мета, удобства, рейтинг, число отзывов, фото карточки, бейдж «Проверено».
- **Колонки в списке площадок:** рейтинг и «Проверено».
- **Хаб «Выгул рядом»** в админ-меню (иконка питомца): сводка + ссылки на разделы.
- **Страница «Настройки каталога»:** заголовок и подзаголовок секции на главной, ссылка «все площадки», число карточек, сортировка (по рейтингу / новые / по алфавиту), показ бейджа «Проверено».
- **Вывод на главной:** если активна тема «Выгул рядом», секция каталога на главной автоматически берётся из плагина (вместо текстовых карточек из настроек темы). Шорткод `[vr_catalog]` — для любой другой страницы.
- **Фильтры-чипы** по типам площадок работают без перезагрузки (JS темы).
- **Страница площадки:** шапка с фото, бейджами, удобствами и рейтингом + блок отзывов (если активен плагин VR Отзывы).
- **Демо-контент при активации:** 4 типа, 4 района и 3 площадки Королёва — каталог выглядит заполненным сразу.

## Установка

1. Скопируйте папку `vr-catalog` в `wp-content/plugins/` и активируйте плагин.
2. Управление: «Выгул рядом → Площадки». Настройки вывода: «Выгул рядом → Настройки каталога».

## Интеграция

- **VR Отзывы** — добавляет блок отзывов на страницу площадки и пересчитывает рейтинг/счётчик в карточках.
- **VR Лиды** — формы заявок для кнопок «Добавить площадку» и «Сдать свою площадку».
