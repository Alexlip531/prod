# VR Лиды

Формы заявок для главной страницы темы «Выгул рядом» и входящие в админке со статусами.

**Требования:** WordPress 6.0+, PHP 8.0+ (разработано под PHP 8.3).

## Что умеет

- **Шорткод `[vr_lead_form type="..."]`** — форма заявки (имя, контакт, комментарий) для любой страницы или виджета.
- **Типы заявок** под кнопки главной: `business` (Подключить бизнес), `host` (Сдать свою площадку), `park` (Добавить площадку).
- **Входящие** — тип записи «Заявка» в хабе «Выгул рядом»: список с колонками (тип, имя, контакт, статус, дата).
- **Статусы заявки:** Новая → В работе → Обработана (меняются в мета-боксе заявки).
- **Email-уведомления** о новой заявке на адрес из настроек.
- **Антиспам:** honeypot-поле + nonce.
- **Страница «Настройки лидов»** в хабе: email получателя, тема письма, текст кнопки, сообщение после отправки.

## Установка и использование

1. Скопируйте папку `vr-leads` в `wp-content/plugins/` и активируйте плагин.
2. Вставьте шорткод на страницу, например: `[vr_lead_form type="business"]` — на страницу «Для бизнеса», `[vr_lead_form type="host"]` — на страницу «Сдать площадку».
3. Кнопки главной (в настройках темы: «Бизнес-баннер», «Частные площадки», CTA в шапке) ведите на эти страницы.
4. Заявки смотрите в «Выгул рядом → Заявки».
