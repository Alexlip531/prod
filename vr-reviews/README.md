# VR Отзывы

Отзывы и рейтинг для площадок сервиса «Выгул рядом»: работают на страницах площадок и обновляют карточки на главной.

**Требования:** WordPress 6.0+, PHP 8.0+ (разработано под PHP 8.3), плагин VR Каталог площадок.

## Что умеет

- **Блок отзывов на странице площадки** — список отзывов с оценками + форма «Оставить отзыв» (имя, оценка 1–5, текст). Вставляется автоматически плагином каталога; вручную — шорткодом `[vr_reviews]`.
- **Автоматический пересчёт рейтинга:** средняя оценка и счётчик («126 отзывов») пишутся в мета площадки — карточки каталога на главной обновляются сразу после публикации отзыва. Корректное склонение («1 отзыв», «3 отзыва», «5 отзывов»).
- **Премодерация** (включается в настройках): отзыв публикуется после одобрения в разделе «Комментарии».
- **Антиспам:** honeypot-поле + nonce.
- **Страница «Настройки отзывов»** в хабе «Выгул рядом»: заголовок блока, текст кнопки, премодерация.
- Отзывы хранятся как комментарии с оценкой — вся штатная модерация WordPress работает из коробки.

## Установка

1. Скопируйте папку `vr-reviews` в `wp-content/plugins/` и активируйте плагин.
2. Откройте страницу любой площадки — блок отзывов уже там. Оставьте тестовый отзыв — рейтинг в карточке на главной пересчитается автоматически.
